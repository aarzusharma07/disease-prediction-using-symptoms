# Disease Prediction System using Machine Learning

An end-to-end machine learning application that predicts a possible disease from user-selected symptoms and serves predictions through an interactive Streamlit application.

## Highlights
- Decision Tree, Random Forest, and Naive Bayes classifiers
- Symptom-to-feature preprocessing
- Model comparison and serialized models
- Interactive Streamlit UI
- Cloud deployment

## ML Workflow
```
Dataset → Preprocessing → Feature Engineering → Training
       → Model Comparison → Serialization → Streamlit Inference
```

## Tech Stack
**Python** · **Pandas** · **NumPy** · **Scikit-learn** · **Joblib** · **Streamlit**

Key Features

-  Symptom-based disease prediction
-  Multiple Machine Learning classification models
-  Decision Tree model
-  Random Forest model
-  Naive Bayes model
-  Prediction confidence score
-  Interactive Streamlit user interface
-  Pre-trained models stored using Joblib
-  Live cloud deployment
-  Model selection through the web interface


## Engineering Focus
Demonstrates an end-to-end ML workflow: data preparation, model training, classifier comparison, model serialization, and deployable inference.

> Educational project; not a medical diagnostic system.
