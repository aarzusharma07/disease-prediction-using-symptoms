

#  Disease Prediction System using Machine Learning

An end-to-end Machine Learning application that predicts potential diseases based on symptoms selected by the user. The project compares multiple machine learning classification models and provides predictions through an interactive web application deployed using Streamlit.

##  Project Overview

The Disease Prediction System is a Machine Learning-based application designed to predict a possible disease based on symptoms selected by the user.

The project follows an end-to-end machine learning workflow, including data preparation, model development, model comparison, model serialization, and deployment through an interactive Streamlit web application.

Users can select symptoms, choose a machine learning model, and receive a predicted disease along with a confidence score.

---

##  Key Features

- 🩺 Symptom-based disease prediction
- 🤖 Multiple Machine Learning classification models
- 🌳 Decision Tree model
- 🌲 Random Forest model
- 📊 Naive Bayes model
- 📈 Prediction confidence score
- 🖥️ Interactive Streamlit user interface
- 💾 Pre-trained models stored using Joblib
- 🌐 Live cloud deployment
- 🔄 Model selection through the web interface

---

##  Machine Learning Models

The application uses multiple classification algorithms to predict diseases based on selected symptoms.

### Models Used

- Decision Tree Classifier
- Random Forest Classifier
- Naive Bayes Classifier

The user can select a model from the application interface and compare predictions generated by different algorithms.

---

##  How It Works

The application follows the workflow below:

1. The user selects symptoms from the web interface.
2. Selected symptoms are converted into machine-readable input features.
3. The selected Machine Learning model processes the symptom data.
4. The trained model predicts the most likely disease.
5. The application displays:
   - Predicted Disease
   - Prediction Confidence
